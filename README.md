# Cloud Computing Lab
## Experiment 01 – Hypervisor Analysis

## Aim

To analyze and compare the performance of Type-1 and Type-2
hypervisors using Proxmox VE and VMware.

---

## Hypervisors Used

### Type-1 Hypervisor
Proxmox VE

### Type-2 Hypervisor
VMware

---

## Objectives

1. Understand the concept of hypervisors.
2. Deploy a virtual machine using Proxmox VE.
3. Deploy a virtual machine using VMware.
4. Perform system performance benchmarking.
5. Monitor CPU and memory utilization.
6. Compare the performance of Type-1 and Type-2 hypervisors.

---

## Experimental Setup

### Type-1 Hypervisor

- Hypervisor: Proxmox VE
- Guest OS: Ubuntu
- Benchmark: Sysbench

### Type-2 Hypervisor

- Hypervisor: VMware
- Guest OS: Ubuntu
- Benchmark: Sysbench
